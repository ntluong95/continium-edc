### Local Machine Setup - Mac

<Info>This guide is recommended for advanced users setting up Continium on a **Mac** machine.</Info>

**Requirements:**

- Node.JS (v20 recommended)
- [pnpm](https://pnpm.io/)
- [Docker](https://www.docker.com/)

**Steps:**

1. **Clone the project & change directory:**

   ```bash
   git clone https://github.com/continium/continium && cd continium
   ```

2. **Setup NodeJS with nvm:**

   ```bash
   nvm install && nvm use
   ```

3. **Install NodeJS packages with pnpm:**

   ```bash
   pnpm install
   ```

4. **Create a development `.env` file and generate the required secrets:**

   ```bash
   pnpm dev:setup
   ```

5. **Start the development databases and run migrations:**

   ```bash
   pnpm db:up
   pnpm db:migrate:dev
   ```

   To test Enterprise features locally, also run the license-server database migration:

   ```bash
   pnpm --filter @continium/license-server db:migrate:dev
   ```

   See [Enterprise License Server](/development/local-setup/enterprise-license-server) for issuing a local key.

6. **Generate the Next.js AGENTS.md file (optional, for AI-assisted development):**

   This step generates an `AGENTS.md` file at the repository root that provides Next.js documentation context for AI coding assistants (e.g. Cursor, GitHub Copilot). It runs `npx @next/codemod agents-md` under the hood. Re-run it whenever you upgrade Next.js.

   ```bash
   pnpm agents:update
   ```

7. **Start the development setup:**
   ```bash
   pnpm go
   ```

Visit [http://localhost:3000](http://localhost:3000) to access Continium.

<Tip>Ensure you create a new account at first login.</Tip>
